Generate RSA Key Pairs inside the HSM

Generate up to 3 independent RSA key pairs. Each private key stays LMK-encrypted inside the HSM boundary. Use different slots to test that signing and verification are truly isolated — a signature from KP-1 must fail verification with KP-2's public key.

Sign Message (EW Command)

Signs a message using an LMK-encrypted private key blob. Paste the key from your saved archive, or use a quick-fill button if you generated one above in Step 1. The HSM decrypts the blob internally — the private key never leaves its boundary.


Verification mode:
Runs EO then EY. Returns EO-formatted key to save.

Verify Signature (EO + EY Commands)

⚡ EY only — paste the EO key you saved from a previous EO+EY result. The HSM skips EO entirely.
Key Block: paste the S-prefixed blob  |  Variant: paste the combined hex (MAC + DER in one string)

Generate Certificate Signing Request (QE Command)

Generates a PKCS#10 CSR entirely inside the HSM using the QE command. The HSM constructs the CSR structure, signs it with the private key, and returns the complete CSR. No Bouncy Castle or external crypto library needed. Requires a key pair to be generated first (Step 1).
